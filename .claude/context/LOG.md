**Decisions:**
- *Build output moved from `docs/` to `app/build/` and is gitignored.* `docs/`
  existed only so Pages could serve from a branch. The workflow runs `npm ci` →
  check → build and uploads what the build wrote, so the live site is always
  built from source.
- *Picsum seeds are now `photo-${n}`,* because the old seeds carried the old
  name. Every thumbnail is a different image as a result; layout, dates and
  placeholder colours are unchanged because they come from the RNG, not the seed
  string. The new seed carries no product name, so a future rename leaves it
  alone.
- *Comments that cited the old app's code as evidence were reworded* to keep the
  reasoning without the citations.
- *The GitHub repo was renamed `Resort` → `resort` by the owner* before this
  landed. Pages paths are case-sensitive (tested: `phpmailer.github.io/PHPMailer/`
  → 200, `/phpmailer/` → 404), so the capital R would have served the site at
  `/Resort/` and 404'd the planned link.
